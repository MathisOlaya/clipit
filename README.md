# 🎥 Clip It

# Démonstration [FR]
**ClipIt** est un SaaS permettant la création de vidéo style TikTok à partir d'un lien et quelque clics. Les captures présentent ci-dessous sont l'ancienne version. Je travaille actuellement sur une V2.

MySQL

Stripe pour les paiements
